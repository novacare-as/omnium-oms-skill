# OmniumProductStatusUpdate

Status update for a single product in a project

**Fields:**

- `skuId`: string, nullable — SKU ID of the product to update
- `status`: string, nullable — New status for this specific product (e.g. Active, Cancelled)
- `cancellationCode`: string, nullable — Cancellation/complaint code for this product
- `cancellationReason`: string, nullable — Free text cancellation/complaint reason
