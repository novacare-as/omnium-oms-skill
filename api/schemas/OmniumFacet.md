# OmniumFacet

Facet

**Fields:**

- `name`: string, nullable — Facet name, e.g. red, green, small, medium, etc.
- `value`: string, nullable — Used for facets that required different values for filtering and displaying. Category name/ID for instance, in that case Value will contain the category ID and Name will contain the category name.
- `count`: integer (int64) — Number of items with this facet
