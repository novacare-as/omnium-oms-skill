**Enum** (string): `ShippingPromotion`, `CategoryOrBrandPromotion`, `MultiBuyPromotion`, `OrderAmountPromotion`, `KitPromotion`, `ProductSearchPromotion`, `PriceListPromotion`, `CostPricePromotion`, `RuleBasedPromotion`
