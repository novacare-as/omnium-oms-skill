# OmniumPromotionKitReward

Reward model for promotion kits (i.e., “Buy a one of each component and get a discount on the kit”).

**Fields:**

- `promotionKitComponentGroups`: List<[`OmniumPromotionKitComponentGroup`](OmniumPromotionKitComponentGroup.md)>, nullable — Component groups that make up the kit.
- `rewardType`: [`KitPromotionRewardType`](KitPromotionRewardType.md)
