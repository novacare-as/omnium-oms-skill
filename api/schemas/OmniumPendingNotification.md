# OmniumPendingNotification

Pending notification that should be picked up by the notification scheduler

**Fields:**

- `notificationId`: string, nullable — Notification ID
- `recipient`: string, nullable — Notification recipient
- `notificationPartitionKey`: string, nullable — Notification partition key
- `notificationName`: string, nullable — Notification name
- `sendDate`: string (date-time) — Scheduled send date
- `notificationGroup`: string, nullable — Notification group
