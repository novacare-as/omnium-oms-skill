# Training

Source: https://docs.omnium.no/docs/training

> Explore Omnium’s training offerings to help users, developers, and consultants fully understand the platform and its features.

## Training Overview

Omnium offers comprehensive training programs to help users, developers, and business consultants understand and effectively utilize the Omnium Order Management System (OMS). The training covers key features, integrations, and API usage, providing all the necessary knowledge to maximize the value of the platform.

## User Training

### Description

A two-to-three-hour session designed for users to get acquainted with the basics of Omnium OMS, covering essential features and operations.

### Agenda

*   Introduction to Omnium OMS
*   Getting Started
*   User Management
*   Carts and Offers
*   Customers
*   Stores
*   Products
*   Order Management
*   Pick Lists
*   Reporting
*   Roadmap and the Future of OMS

## Developer Training

### Description

A half-day course for developers to learn how to interact with and utilize Omnium APIs for integrations and customizations.

### Agenda

*   About Omnium OMS
*   Getting Started
*   Authentication
*   Configurations
*   Stores and Markets
*   Order Fulfilment
*   Carts and Offers
*   Main Demo
*   API Introduction

## Business Consultants Training

### Description

A half-day training session tailored for Omnium partners, teaching business consultants how to implement and set up Omnium OMS for their customers.

### Agenda

*   About Omnium
*   Demo
*   Technical Architecture
*   Partner Program
*   Standard Integrations
*   Custom Integrations
*   Product Components
*   Customer Cases
*   Roadmap
*   Q&A
