# Tutorials

Source: https://docs.omnium.no/docs/GettingStartedWithAPI/Tutorials

> Step-by-step guides that walk you through complete integration scenarios with Omnium — from first API call to production-ready workflows.

These tutorials are hands-on, end-to-end walkthroughs. Each one starts from scratch and builds up a working integration, covering the API calls, data models, and best practices you need along the way.

If you're looking for reference documentation instead, check the domain-specific sections (Orders, Products, Inventory, etc.) in the sidebar.

* * *

## Available tutorials

*   [Omnichannel E-commerce](Tutorials/omnichannel-ecom.md) — Set up markets, stores, products, inventory, cart checkout, and click & collect from scratch
*   [ERP Integration](Tutorials/erp-integration.md) — Subscribe to order events, sync inventory, report shipments, and process returns
*   [POS Integration](Tutorials/pos-integration.md) — Push in-store sales and returns, transfer orders to the store, and sync store inventory
