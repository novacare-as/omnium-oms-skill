# Supported Payment Providers

Source: https://docs.omnium.no/docs/plugins/POS/Sitoo/hidden

> Omnium support for payments created in Sitoo

Omnium supports many payment providers but not all currently work out of the box with Sitoo. This means that you might not be able to capture, credit or cancel a payment in Omnium if it was created in Sitoo unless we support the provider in this regard. Here are the currently supported payment providers:

*   Adyen
