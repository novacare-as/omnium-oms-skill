# PowerOffice

Source: https://docs.omnium.no/docs/plugins/ERP/PowerOffice

Omnium supports exporting invoices to Power office. Invoice exporter creates one common invoice for all shipments on an order. Order exporter creates one invoice per shipment.

Payment export scheduled task is used together with the order exporter and creates one bank voucher per payment type per day with transactions matching the invoices for the order that have been paid
